# ODA Burger bilingual restaurant website

## Build
- Replace the placeholder homepage with a polished, mobile-first ODA Burger experience using the supplied logo and food photography.
- Create a sticky bilingual navigation, premium food-led introduction, customer favorites, interactive menu, concise story, social gallery, contact/location, hours placeholder, and footer.
- Support natural English and Arabic layouts, including full RTL mirroring and translated interface text.

## Ordering
- Add category tabs and product cards driven by one editable restaurant data structure.
- Add product detail dialogs with sandwich/meal selection where applicable.
- Add a working cart with quantities, removal, totals, and WhatsApp checkout to +973 3390 3421.

## Visual direction
- Use warm cream, deep burgundy, red, and dark brown with strong display type and restrained Japanese street-food details.
- Keep motion subtle and controls touch-friendly, with a persistent mobile order action.

## Validation
- Check desktop and mobile layouts, Arabic RTL, language switching, category filtering, dialogs, cart updates, generated WhatsApp order links, navigation, images, and metadata.

## Technical details
- Keep the existing TanStack Start foundation while delivering the requested React/Tailwind experience; this project does not support replacing its fixed framework with Next.js.
- Store uploaded media through the project asset system and centralize menu, contact, social, and hours data for future editing.
